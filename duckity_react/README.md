# Duckity React SDK

Welcome to Duckity's official React SDK. This SDK enables you to build client apps that solve
Duckity challenges to protect your servers.

The documentation for this SDK available in [Duckity's Documentation], together with guides and
examples you may find useful. Need help? File an issue in our [SDKs GitHub repository].
