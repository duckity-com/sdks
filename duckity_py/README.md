# Duckity Python SDK

Welcome to Duckity's official Python SDK. This SDK enables you to:

- Build client apps that solve Duckity challenges, and
- Build server applications that validate challenges issued by clients.

The documentation for this SDK available in [Duckity's Documentation], together with guides and
examples you may find useful. Need help? File an issue in our [SDKs GitHub repository].
